# Re-examination standards by ground, and special situations

Part of the `examine-draft-response` skill. In Step 2, read the section for every ground the original OA raised and every ground the amendments newly attract. Apply the standard of the named `check-*` skill as an examiner would, in one coherent communication.

## Contents

## Art. 54 — novelty (`check-art-54-epc`)

Direct and unambiguous disclosure of every feature in a **single** document; no mosaicking across embodiments (T 261/15 sub-range test).

## Art. 56 — inventive step

Problem–solution approach (Guidelines G-VII, 5): closest prior art, distinguishing features, technical effect, objective technical problem, could–would. Check whether the **amended** claim still falls under the combination the original OA used, and whether the technical effect the strategy relies on is derivable from the application as filed. If it is not (G 2/21), refuse the effect for problem–solution; the objection then likely stands.

## Art. 83 — sufficiency (`check-art-83-epc`)

Does the amended claim, especially when narrowed to an embodiment or a parameter range, remain enabled across its whole scope? Do imported features raise enablement or plausibility (G 2/21) concerns? (T 409/91, T 435/91.)

## Art. 84 — clarity, conciseness, support (`check-art-84-epc`)

New relative terms, optional features, missing essential features, mixed categories, unmeasurable parameters, or a broken support relationship with the description (Guidelines F-IV, 4–6). G 3/14 limits Art. 84 only in opposition — do not apply it in examination.

## Art. 123(2) — added matter (`check-art-123-2-epc`)

Gold Standard (G 2/10): every amendment directly and unambiguously derivable from the application as filed, with citation. Watch for intermediate generalisation (T 962/98) — name it explicitly where the strategy combines features from different embodiments — multiple independent selections (T 727/00, T 686/99), combined range end-points (T 2/81, T 1170/02), and disclaimers (disclosed: G 2/10; undisclosed: G 1/03, G 2/03, G 1/16). If a feature has no basis, name the precise gap.

## Art. 76(1) — divisional basis (`check-art-76-1-epc`)

Only for a divisional: basis in the parent as filed and in each earlier application.

## Other grounds newly attracted

Raise only if the amendments visibly attract them: Rule 43(2) EPC for several independent claims of one category outside Rule 43(2)(a)–(c); Art. 82 unity if the amendments split the inventive concept.

## Special situations

- **Argument-only strategy:** re-examine the unamended claims and address each argument directly — does it defeat the original objection?
- **Auxiliary requests:** examine every pending request in turn.
- **Contradictory strategy** (e.g., an auxiliary request broader than the main request): point it out in the debrief and examine each request independently; do not fix it.
