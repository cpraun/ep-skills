# Sufficiency tests by claim type

Part of the `check-art-83-epc` skill. Read the section for each claim type identified in Step 2, and the G 2/21 section whenever a technical effect is relied on (Step 3).

## Contents
- Technical effect and plausibility (G 2/21)
- Parameter-based claims
- Functional and reach-through claims
- Ranges
- Use claims
- Computer-implemented inventions
- Biological material

## Technical effect and plausibility (G 2/21)

Applies only where the claim relies on a technical effect (e.g., "compound X for treating disease Y", "a composition having improved stability", a parameter whose effect carries patentability). Otherwise do not invoke G 2/21.

- The application as filed must make the effect plausible to the skilled person; a bare assertion is not enough.
- Post-published evidence may be relied on if the effect is encompassed by the technical teaching and embodied by the same originally disclosed invention. It can supplement plausibility at filing, not replace it.
- If the alleged inventive contribution is a technical effect, the skilled person must be able to achieve it across the scope of the claim (type: Inventive contribution not reproducible).

## Parameter-based claims

The application must enable the skilled person to obtain values within the claimed range across the scope; values that cannot be reached are a sufficiency issue (type: Parameter unobtainable). A parameter that cannot be measured is primarily a clarity issue (Guidelines F-IV, 4.11); an ambiguous parameter leads to insufficiency only where it prevents carrying out the invention (T 593/09; Guidelines F-III, 12; for a case where it did: T 1845/14).

## Functional and reach-through claims

A claim defined by a function (e.g., "a compound that inhibits enzyme X") is sufficient only if the skilled person can identify, without undue burden, embodiments that satisfy the function. A mere invitation to research is insufficient (T 435/91; reach-through claims: T 1063/06, Guidelines F-III, 9).

## Ranges

Enablement must extend across the entire range. Examples near the end-points may be needed if the effect varies across the range.

## Use claims

"Use of X for Y" requires that X actually achieves Y as claimed.

## Computer-implemented inventions

The skilled person must be able to implement the claimed functionality. A claim defined only by what the software achieves, without algorithmic detail, may be insufficient if the implementation is not trivial.

## Biological material

If the invention requires biological material that is not available to the public and cannot be reproduced from the description, a deposit is required (Rule 31 EPC).

## Working and prophetic examples

A single working example may suffice for a narrow claim, rarely for a broad one; the number and diversity of examples should match the breadth of the claim. Prophetic examples are acceptable but carry less weight; a broad claim with only prophetic examples tends toward insufficiency.
