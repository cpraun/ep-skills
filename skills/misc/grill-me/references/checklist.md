# What must be clear, by task

Part of the `grill-me` skill. Use only the row for the task at hand, and ask only about points not already settled.

| Task / skill | What must be clear before it can be run reliably |
|---|---|
| `analyze-oa`, `draft-oa-summary` | Which communication (date, type); the claims and application the OA refers to; all cited documents D1…Dn available; whether a client report or an internal analysis is wanted; language |
| `suggest-oa-response-strategies` | Client goals and priorities (scope vs. speed vs. cost); acceptable fall-back positions; products or competitors to protect; any parallel proceedings; embodiments with real commercial value; the application as filed |
| `draft-oa-response` | Which strategy was chosen (and that it was chosen by the attorney); claim set to file; basis for every amendment; arguments to run or avoid; filing posture (main/auxiliary requests; oral proceedings requested?) |
| `examine-draft-response` | The strategy or draft in concrete wording; the pending claims; the application as filed; all D-documents |
| `check-art-123-2-epc`, `check-art-76-1-epc` | The exact amended wording; the application as filed (for divisionals: the parent as filed); which version is the reference |
| `check-art-54-epc` | The claim; the single document D1 and its language; which claim features the user thinks are at issue; priority date and effective filing date if relevant |
| `check-art-83-epc`, `check-art-84-epc`, `check-claim-formalities-epc` | The claims; for Art. 83 the description; the field and the skilled person if disputed |
| `check-prefiling` | Origin and status of the draft; claim set and description complete; filing route (direct EP, Euro-PCT, priority claim and date); the target jurisdictions |
| `suggest-claim-reduction`, `suggest-claim-dependencies` | The claim set as it stands for EP entry; the application as filed; the target count; which independent claims are untouchable |
| `translate-en-de`, `verify-en-de-translation` | The source (and target) text; purpose (R. 71(3) claims, validation, other); binding glossary or parent translation; doubtful terms |
| `compute-time-limit-epc` | The event and its date; which document; the legal basis; any extension or remedy already used |
| `verify-citations` | The draft to check; the sources to check it against, with their locations |
| Anything else | The goal in one sentence; what 'done' looks like; documents; deadline; what is already decided |
